# Unicode 15.0.0 source data

These are the exact Unicode Character Database 15.0.0 source files used to
generate Worldspeaker's public-reply body classification tables. `ReadMe.txt`
identifies the released version and source date. The SHA-256 values pinned in
`tools/unicode/manifest-15.0.0.json` are checked before generation.
